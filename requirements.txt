# StashVision Pro App Requirements

## Overview
Create a native visionOS (Apple Vision Pro) client for Stash, a self-hosted media server and organizer. The app should provide an immersive and intuitive way to browse, search, and play media content from a Stash server, with special optimization for the Vision Pro's unique capabilities.

## Stash API Implementation Details
The app must interact with several Stash API endpoints:

### GraphQL Endpoints
- `FindScene(id: ID!)` - Get scene details by ID
- `FindScenes(filter: SceneFilterType, scene_filter: SceneFilterType)` - Query scenes with filters
- `FindPerformers(filter: PerformerFilterType)` - Query performers with filters 
- `FindTags(filter: TagFilterType)` - Query tags with filters

### Direct Media URLs
- Scene Direct Stream: `{serverURL}/scene/{id}/stream?apikey={key}`
- Scene HLS Stream: `{serverURL}/scene/{id}/stream.m3u8?apikey={key}&resolution={res}`
- Scene Screenshot: `{serverURL}/scene/{id}/screenshot?t={timestamp}&apikey={key}`
- Scene Preview: `{serverURL}/scene/{id}/preview?apikey={key}`
- VTT Thumbnails: `{serverURL}/scene/{fingerprint}_thumbs.vtt?apikey={key}`
- Sprite Sheet: `{serverURL}/scene/{fingerprint}_sprite.jpg?apikey={key}`

### Authentication
- API Key authentication via:
  - HTTP header: `ApiKey: {key}`
  - URL parameter: `?apikey={key}`
  - Authorization header: `Authorization: Bearer {key}`

## Stash Data Models
The app needs to implement Swift models that match Stash's data structure:

### Scene Model (Key Fields)
```swift
struct StashScene: Identifiable, Decodable {
    let id: String
    let title: String
    let details: String?
    let url: String?
    let date: String?
    let rating100: Int?
    let performers: [StashPerformer]?
    let tags: [StashTag]?
    let studio: StashStudio?
    let files: [StashFile]?
    let paths: ScenePaths?
    let created_at: String?
    let updated_at: String?
}

struct StashFile: Decodable {
    let id: String?
    let path: String?
    let size: Int?
    let duration: Double?
    let video_codec: String?
    let audio_codec: String?
    let width: Int?
    let height: Int?
    let framerate: Double?
    let bitrate: Int?
}

struct ScenePaths: Decodable {
    let screenshot: String?
    let preview: String?
    let stream: String?
    let webp: String?
    let vtt: String?
    let sprite: String?
    let funscript: String?
    let interactive_heatmap: String?
}
```

### Performer Model
```swift
struct StashPerformer: Identifiable, Decodable {
    let id: String
    let name: String
    let gender: String?
    let url: String?
    let twitter: String?
    let instagram: String?
    let image_path: String?
    let scene_count: Int?
    let tags: [StashTag]?
}
```

### Important Considerations
- Scene "fingerprints" (like oshash, MD5, etc.) are needed for VTT/sprite files
- Stash supports multiple video file formats, some requiring HLS for smooth playback
- HEVC/H.265 codec videos often need special handling with HLS streaming
- Resolution options for HLS: "240p", "480p", "720p", "1080p", "4k", "original"
- VR content detection via tags containing "vr", "180", or "360"
